[WHY join() IS THE RECOMMENDED PRACTICE DESPITE CPYTHON += OPTIMIZATION]
1. In Python, strings are immutable. Naively, 's += x' creates a new string copying all previous characters,
   leading to O(N^2) cumulative character copying.
2. CPython implements an optimization where if reference count == 1, it attempts in-place realloc.
   However, as seen at N=200,000, when heap fragmentation occurs or reference counts change,
   += runtime degrades to 0.23 seconds.
3. str.join() guarantees strictly linear O(N) time across all Python interpreters.
   It computes the total length in Pass 1, allocates one single memory buffer, and copies parts once in Pass 2.
